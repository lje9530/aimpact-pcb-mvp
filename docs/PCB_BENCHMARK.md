# PCB 외관검사 모델 벤치마크

## 대상과 데이터 선택

공정은 PCB 회로패턴의 AOI 후 최종판정 보조입니다. 대표 유형은 단선, 단락, 마우스바이트, 돌기, 잉여 구리이며 예제 데이터에 포함된 핀홀도 표시합니다. `미분류`는 담당자가 기록할 수 있습니다.

| 데이터 | 쓰임 | 근거와 제약 |
|---|---|---|
| DeepPCB | 로컬 연구 시연 및 1차 벤치마크 | 1,500개의 정렬된 기준·검사 영상 쌍과 6개 유형 라벨. 일부 불량은 저자가 합성했으며 데이터 사용 범위는 연구용입니다. [저자 저장소](https://github.com/tangsanli5201/DeepPCB) |
| DsPCBSD+ | 실제 생산 PCB로 외부 검증 | 실제 제조업체 PCB에서 수집한 9개 유형 데이터입니다. 현 과제 유형과 대응하는 라벨을 정하고 평가해야 합니다. [데이터 논문](https://www.nature.com/articles/s41597-024-03656-8) |
| DefectDet | 더 높은 해상도의 보드 전체 시연, 보조 검증 | 실제 제조된 이중층 PCB 268장, 약 1000–2400px, 단선·단락 등 5개 유형입니다. 불량은 설계 단계에 의도적으로 넣었고 기준 영상 쌍이 전제되지 않습니다. [Mendeley 원본](https://data.mendeley.com/datasets/t9d9zs3bmb/1) |

DeepPCB 이미지의 컬러 라벨은 파일과 분리되어 있습니다. 표시를 지우면서 픽셀을 보정할 필요가 없습니다. 기준 영상과의 이진 차이를 주황색으로 덧그리며, 개별 후보를 선택할 때만 위치 테두리를 표시합니다. 영상 쌍을 제공하는 기업 샘플이 있다면 독립 정상 촬영본과 함께 확인하는 것이 다음 검증의 우선순위입니다.

## 실행 결과

같은 그룹이 여러 분할에 나타나지 않도록 그룹 기준으로 분리했습니다. 학습 7개 그룹 1,000쌍, 검증 2개 그룹 112쌍, 테스트 2개 그룹 220쌍입니다. 정상 대조군은 같은 테스트 그룹의 기준 영상을 자기 자신과 비교한 220건입니다. 실제 정상 제품의 독립 촬영 사례는 이 평가에 포함되지 않습니다.

두 모델은 밝기 이진화→정렬된 기준 영상과의 차이→연결요소의 크기·형상·부호·주변 밀도 특징을 공유합니다. 검증에서 유형 F1로 점수 임계값과 모델을 골랐습니다. 유형 지표에는 클래스 일치와 IoU 0.19 이상의 1대1 매칭이 필요합니다. 라벨 박스는 실제 픽셀 변화보다 넓어 낮은 IoU 기준을 사용했습니다. DeepPCB 공식 검출 점수와 수치를 직접 비교하기 어렵습니다.

| 후보 | 검증 유형 F1 | 테스트 유형 F1 | 테스트 이미지 불량 Recall | 테스트 이미지 F1 |
|---|---:|---:|---:|---:|
| 다항 로지스틱 회귀 | 0.131 | 0.169 | 100.0% | 1.000 |
| 랜덤 포레스트 · 채택 | 0.382 | 0.432 | 92.7% (204/220) | 0.962 |

랜덤 포레스트는 유형 오탐과 미탐을 합친 기준에서 우세했습니다. 보류된 테스트 보드 220장에 대한 CPU 중앙값은 **15.6ms**, p95는 **34.2ms**, 압축 모델 파일은 **0.70MB**입니다. CPU 시간은 이미지 디코딩·저장·HTTP 요청을 제외한 1장당 전처리와 추론 시간입니다. 제안서의 이미지 불량 Recall 95% 목표와는 2.3%p 차이가 있습니다. 단선 287개 중 46개, 단락 219개 중 63개, 돌기 212개 중 15개가 유형과 위치 모두 일치했습니다.

정상 대조군에서 두 모델 모두 오탐이 0건인 결과는 기준 영상 자기 비교 조건에 해당합니다. 이미지 F1은 그 대조군과 여러 결함이 함께 들어간 검사 영상으로 계산했습니다. 이번 실행 비교는 위의 두 모델에 한정했습니다. 실제 정상 영상 오검률, 신규 결함 AUROC, 기업 표본 일반화는 후속 검증 대상입니다. 정렬 영상이 확보되지 않는 협력사의 경우 실제 정상·불량 자료를 모아 ResNet-50, EfficientNet/MobileNet, PatchCore를 비교하는 편이 적합합니다.

## 재현

버전이 고정된 원본 ZIP과 [학습](../data/splits/train.csv)·[검증](../data/splits/validation.csv)·[테스트](../data/splits/test.csv) CSV로 재현합니다. 학습 단계에서 모델과 임계값을 검증 데이터로 선택해 저장하고, 별도의 평가 단계에서 테스트 레이블과 대조합니다. [데이터 구조와 재현 명령](PCB_REPRODUCTION.md)

[v0.1.0 benchmark.json](../data/pcb_demo/benchmark.json)에 당시 원본 ZIP의 SHA-256, 그룹, 선택 임계값과 유형별 TP·FP·FN을 기록했습니다. 새로 실행한 결과는 `outputs/reproduction/`에서 비교할 수 있습니다.
